AIJ User Guide

1. Start Securely

  • The app creates a session token automatically.
  • Click AIJ any time to reopen this guide.

2. Choose a Model Tier

  • Free models are available immediately.
  • Premium models require server plan keys or BYOK token connection.

3. Connect BYOK Tokens

  • Select a provider in Connect Token.
  • Paste token and click Connect Token.
  • Tokens are encrypted server-side and tied to your session identity.

4. Run Analysis

  • Write a detailed journal entry (80+ chars recommended).
  • Click Analyze Entry to run sentiment, insights, and summary.

5. Read Diagnostics

  • Each card displays provider, confidence, and fallback reason if used.
  • Diagnostics panel shows provider configuration and fallback counters.
